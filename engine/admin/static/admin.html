Deploy

Publish → live in the top bar builds the site and deploys it to the provider below. Each provider needs its own API token for your account — tokens stay on this machine only (admin/secrets.env).

Custom domain how-to
  1. Buy/point your domain's DNS to Cloudflare (free plan works).
  2. In the Cloudflare dashboard open Workers & Pages → your project → Custom domains and press Set up a custom domain. Follow the CNAME instructions it gives you.
  3. Wait a bit — Cloudflare issues the SSL cert automatically (usually under ~15 min).
  4. Back here, put your domain into the Site → domain field in the Site & SEO tab (without a trailing slash, e.g. https://mysite.com) — it is used for canonical and Open Graph links.
  5. Save, then press Publish → live once. Done — the site answers on your domain.
  6. Keep your-project.pages.dev working as the fallback address.

Path-only /admin/api/siteinfo and image/media paths are relative, so they keep working on any domain automatically.
